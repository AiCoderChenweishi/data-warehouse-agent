0530 秒本地跑起来

克隆 → 装依赖 → 起后端 → 起前端,4 条命令搞定。

git clone https://github.com/AiCoderChenweishi/data-warehouse-agent
cd data-warehouse-agent

# 装依赖 (DuckDB / FastAPI / Streamlit)
pip install -r app/backend/requirements.txt
pip install -r web/requirements.txt

# 起后端 (端口 8000)
bash app/backend/run.sh

# 起前端 (端口 8501, 新终端)
bash web/run.sh

# 打开浏览器
open http://localhost:8501
